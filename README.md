# -ai-
本来只是想做一个电子相册，发现这样模拟很好玩
主要用于模拟一个带弹幕、AI 观众、装扮系统的十周年纪念直播间。核心功能如下：

一、照片相册管理
上传照片（转为 base64 存储）

为每张照片添加配文（可手动输入，也可让 AI 看图建议配文）

删除照片、切换当前展示照片

照片会在直播间「舞台」区域展示

二、直播间系统
开播 / 下播流程：可设置直播标题、封面

实时弹幕：

弹幕以飞行样式从右向左飘过

支持普通弹幕、付费留言（SuperChat）、系统通知

弹幕可以带昵称、头像颜色

侧边弹幕墙：展示弹幕历史记录（含付费留言高亮）

主播麦克风：主播可以说话 / 发付费留言，AI 观众会接话或反应

照片轮播：可切换展示不同照片

观众人气系统：实时观看人数（模拟自然波动）

仪表盘：粉丝数、心情、压力、好感度（会受主播行为/事件影响）

三、AI 驱动内容（核心亮点）
所有弹幕都由 AI 实时生成，不再使用本地语料兜底（只在无 AI 时降级）

AI 会：

根据照片内容（或配文）+ 直播氛围 + 最近弹幕 + 事件（如切照片、改名、发付费留言）生成弹幕

支持看图（视觉模型）或只看配文（更快）

生成弹幕时区分普通观众 / 高亮付费留言 / 系统通知

支持手动刷新弹幕（强制 AI 重新看当前照片）

支持定时自动刷新弹幕（可设置间隔）

AI 测试功能：在后台可测试 AI 连接是否正常，并预览它会为某张图生成哪些弹幕

四、主播模拟器 & 事件系统
随机事件卡：

冲上热门、黑粉空降、冷场、榜一大哥空降

影响人气、粉丝、心情、压力

礼物雨、涨粉飘字特效

主播行为（开麦、改名、上传照片、发付费留言）会触发观众反应 & 数值变化

五、装扮系统（像素风）
一键主题：同时切换背景、边框、字体、主色调

边框：内置多种像素边框，也支持上传自定义图片边框

背景：内置多种像素背景，支持上传图片背景（舞台 + 网页背景）

字体：内置像素 / 圆体等字体

贴纸：

内置大量像素风格贴纸（爱心、星星、皇冠、蛋糕、音符等）

支持上传自定义贴纸

贴纸可拖拽位置、缩放大小、删除

六、多身份 & 好友共创
可创建多个身份（昵称 + 颜色）

切换当前身份发弹幕

把存档文件发给朋友，朋友切到自己的身份发弹幕，再导出回传 → 接力共创

七、直播大厅
展示我的直播间卡片（可进入开播/观看）

展示多个 NPC 直播间（美食、唱歌、学习、萌宠、游戏等）

点击 NPC 直播间可进去“逛”，看到模拟弹幕、发送弹幕（本地体验）

提示：真·云端联播需要服务器，本 app 通过导入好友存档实现类似效果

八、AI 酒馆（后台配置）
总开关：启用/禁用 AI、自动路人弹幕、定时刷新

世界观预设：描述直播间氛围、人物关系等，喂给所有 AI 观众

观众人设管理：

可增删改观众人设（名称、颜色、性格 prompt、付费概率）

API 设置（支持 OpenAI 兼容接口）：

填写 Base URL、API Key

拉取模型列表

分别设置「文本模型」和「看图模型」（看图模型可留空，只读配文更快）

测试连接与弹幕生成

密钥仅存储在本地 / 导出文件中（导出时可选择是否带 Key）

九、存档与分享
导出为完整 HTML 文件：

照片会以 base64 打包进去

可选择是否包含 API Key

朋友打开后可直接使用（需自己填 AI Key 才能生成弹幕）

导入/导出 JSON 存档

历史记录：记录关键操作（上传、开播、AI 生成等）

重置全部：清空所有数据恢复初始状态
